# Interactive To-Do List Web Application

A responsive and dynamic To-Do List web application built using HTML5, CSS3, and JavaScript. This app allows users to manage their daily tasks efficiently with real-time DOM manipulation.

## 🚀 Live Demo
[Click here to view the Live Application](https://anithamadina.github.io/todo-list-web-app/)

## ✨ Features
* **Add Tasks:** Quickly add new tasks with validation to prevent empty entries.
* **Delete Tasks:** Remove completed or unneeded tasks with a single click.
* **Responsive UI:** Clean, minimalist, and mobile-friendly design centered layout.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3
* **Scripting:** JavaScript (DOM Manipulation)
